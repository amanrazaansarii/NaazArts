# Skill Selector

## Usage
`
/run skill-selector " Brief description of the task you want to achieve.\
`

The skill will:
1. Scan all sibling skill folders under the workspace's skills directory.
2. Parse each SKILL.md to extract the description field.
3. Compute a relevance score between the task description and each skill description.
4. Select the top‑N skills (default = 3) and invoke them via Antigravity sub‑agents.
5. Return a summary of the actions performed and any outputs.

## Parameters
- ask_description (string, required): The natural‑language description of the work you need done.
- max_results (int, optional, default = 3): Maximum number of skills to invoke.

## Limitations
- Currently uses simple keyword overlap (Jaccard similarity) for relevance.
- Invoked skills must be callable via Antigravity’s sub‑agent API.
